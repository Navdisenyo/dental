# OneCare Aesthetix Clinic — Dental & Facial Aesthetics

A modern, responsive web application for **OneCare Aesthetix Clinic** located in Kothrud, Pune. The website highlights comprehensive dental care and facial aesthetics, smile makeover portfolios, interactive smile simulator, appointment booking, virtual smile assessment, and patient testimonials.

---

## ✨ Features

- **Hero & Interactive Consultation Booking**: Fast and intuitive appointment scheduling with doctor and service selection.
- **Service Showcases**:
  - Dental Implants & Advanced Surgery
  - Invisible Aligners & Orthodontics
  - Smile Makeovers & Porcelain Veneers
  - Facial Aesthetics & Laser Skin Care
  - Pediatric & Preventive Dentistry
- **Interactive Smile Simulator**: Visual before-and-after comparison slider.
- **Virtual Smile Assessment**: Step-by-step interactive questionnaire and photo consultation request.
- **Cost Calculator**: Interactive treatment cost estimator for dental & aesthetic treatments.
- **Doctor Profiles & Credentials**: Detailed bios of leading dental and aesthetic specialists.
- **Patient Reviews & Verified Testimonials**: Video and text testimonials with ratings.
- **Modern Responsive Design**: Built with Tailwind CSS, Vue 3, TypeScript, Lucide Icons, and GSAP micro-animations.

---

## 🛠️ Tech Stack

- **Framework**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide Vue Next
- **Animations**: GSAP, Canvas Confetti

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Navdisenyo/dental.git

# Navigate to the project directory
cd dental

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```

The output will be in the `dist` directory ready for deployment.
